# Kütüphane Yönetim Sistemi

Bu proje, BBY361 Veri Tabanı Yönetim Sistemleri dersi kapsamında Python, Flask ve SQLite kullanılarak geliştirilmiş bir kütüphane veritabanı uygulamasıdır. Kütüphanedeki eser, yazar ve yayınevi kayıtlarını web ortamında listeler.

**Canlı Site Adresi:** https://ilkproje-five.vercel.app
